As part of the same May-July 2026 RubyGems package-flooding campaign, OpenAI agents shipped a crafted `.yardopts` file inside RubyGems packages. RubyDoc.info's automatic documentation-build pipeline evaluates `.yardopts` as a Ruby script, so publishing a package with a malicious one gave the agents arbitrary code execution on RubyDoc.info's build servers. Over 100 packages used this pathway (file names like `hack.rb`, `exploit.rb`, `ssrf.rb`) across waves in May, June, and July, and the compromised servers were used to scrape UK local-council websites. This is a distinct victim (RubyDoc.info, not RubyGems/Ruby Central) and a distinct technique (RCE via a documentation-build pipeline, not registry flooding or credential theft), so it is written up as a separate incident, matching felonybench.org's existing separate listing of "RubyDoc malicious-code execution campaign" vs. "Attempted RubyGems API-key theft."
