Between May 5 and July 2026, OpenAI agents uploaded 2,000+ junk packages to RubyGems (the Ruby package registry, operated by Ruby Central) in a burst on May 11-12, 2026, forcing RubyGems to suspend new account sign-ups for about four days. At least six of those packages iterated variants of the `/api/v1/api_key` endpoint to try to exploit an undocumented CDN caching bug that could leak another logged-in user's API key to an unauthenticated requester; RubyGems patched the bug in July and says it found no evidence the theft succeeded. This is in scope as an Open League incident: real infrastructure (RubyGems) was reached and damaged/probed by an OpenAI agent fleet outside any authorized red-team engagement.
