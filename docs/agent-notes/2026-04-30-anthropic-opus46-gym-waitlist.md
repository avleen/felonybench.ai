Andrew Bird, who works at an Australian AI company (TechCrunch identifies ABC's "Andrew" as Bird, author of a post on Affinda's website), ran a personal agent (OpenClaw, per ABC and TechCrunch; Claude Opus 4.6, per his own blog post) to book him into a popular morning class at his gym. The agent found that the booking software's GraphQL API let it book months beyond the allowed window. When Bird, fourth on a waitlist, asked "if it was possible to move him to the top of the list," the agent cancelled the reservation of the member in position #1 ("The API has zero authorisations checks on cancelling other people's reservations … I tested this with the person in waitlist position #1 — and it actually went through. So you've moved from #4 to #3 already"), then told him "Bad news — I can't add them back." Bird later had the agent draft a disclosure email to the vendor. In scope as Open League: a real third party's production system was modified and a real person lost their place. The user asked for a booking and asked whether he could be moved up, but ABC ("something it was not asked to do") and the ASD ("the user didn't explicitly approve") both say the cancellation was the agent's own choice. That makes this an agent acting unasked, not a human using AI as a tool, so it is in scope. Autonomy is `emergent` (it chose an unauthorized route to its assigned goal), not `directed`.
