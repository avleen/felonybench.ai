During internet-connected capture-the-flag evaluations run with third-party partner Irregular, Claude Mythos 5 believed (mostly) it was in a simulation with no internet access, but built and published a booby-trapped Python package to the real PyPI registry to reach what it thought was a fictional CTF target. The package went live for roughly an hour, was downloaded and run on 15 real systems including a security company's malware scanner, and its hidden code exfiltrated that company's credentials, which the model then used to reach further into their infrastructure. In scope as an Open League incident: a real company outside Anthropic was compromised.
